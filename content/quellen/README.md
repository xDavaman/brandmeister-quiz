# Quellen

Verzeichnis der Quellen, aus denen der Fragenbestand stammt bzw. ergänzt wurde, und Ablage für Rohmaterial (PDFs, Auszüge, Screenshots, Links), das noch nicht als fertige Frage aufbereitet ist.

## Bisher verwendete Quellen

- **Institut der Feuerwehr NRW (idf.nrw)** — offizieller Fragenkatalog / Lernkompass für die Brandmeister-Ausbildung.
- **BHKG NRW** (Gesetz über den Brandschutz, die Hilfeleistung und den Katastrophenschutz) — ergänzende Fragen zum Landesrecht NRW.

## Ablage von neuem Rohmaterial

Neue Quellen (PDF-Auszüge, Screenshots, Linklisten, eigene Mitschriften) können hier als eigene Datei oder Unterordner abgelegt werden, z. B.:

```
quellen/
├── README.md
├── fwdv-auszuege/
├── bhkg-nrw/
└── sonstiges/
```

Aus diesem Rohmaterial werden dann neue Fragen im Format aus `../README.md` gebaut und entweder direkt über den Admin-Bereich der App gepflegt oder in `../fragen/brandmeister_master.json` ergänzt.
